# 8. Filtering and selecting rows

In module 5, you used `sbp[2]` to pick out one value from a vector. A data
frame has two directions, so its square brackets take two things: a row,
then a column, separated by a comma. It's like finding a seat in a theatre —
row first, then seat. It's also one of the easiest things to misread in
generated R, because it's easy to mix up which one comes first.

## Keeping the rows you want

With vectors, you could put TRUEs and FALSEs inside the square brackets to
keep only the values you wanted. The row side of a data frame's brackets
works exactly the same way.

## When a missing value invents a patient

In a vector, a missing value is just one value. In a data frame, it can be
much worse. Filter on a column that is missing a value, and R can add a row
that isn't any patient at all — and count it as if it were.
