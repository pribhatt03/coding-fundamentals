## Enough, and no more

<!-- TODO: the balance. Tell the AI everything that changes the code — names,
     types, quirks, clinical decisions — and nothing that doesn't: the
     study's aim, the real values, where the data came from. The less you
     share, the less can leak, about patients or about an unpublished idea.
     Placeholder names protect an idea too — but you're then showing a
     different example, so map the names back carefully when code returns.
     A simple example is often the clearest way to show what you mean. When
     you simplify, ask: is it still representative? Does it still have the
     missing value, the odd entry, the boundary case? -->
