# 7. Shape and inspection

Think of each thing you measure (age, blood pressure, whether they've gone
home) as one vector, with one value per patient. If you line those vectors
up side by side, you get a table.

In R, that table is a *data frame*, and `data.frame()` builds one from
vectors:

```r
patients <- data.frame(
  age        = c(67, 54, 71, 48, 62),
  blood_type = c("A+", "O-", "B+", "O+", "A-"),
  sbp        = c(142, 118, NA, 131, 156),
  discharged = c(TRUE, FALSE, FALSE, TRUE, TRUE)
)
```

Four vectors, five patients each. And notice the three kinds of column —
numeric, character and logical — the same three types from module 3, now
side by side.

::: exercise {#ch07-ex01}

By convention, each row is one patient and each column is one thing measured
about everybody. The table you just clicked on is how RStudio shows a data
frame when you open it to look at it: column names across the top, row
numbers down the side.

## Looking at what R thinks

Looking at a data frame won't tell you what type each column is. A column of
*numbers* and a column of *text that happens to look like numbers* appear
exactly the same. The `str()` function shows you exactly how R sees it.

R makes decisions like that quietly, all the time. Most of them are fine.

missing test — is the part only you can do.
