## Choosing one path with if

`if` checks a condition that is either TRUE or FALSE, and runs one of two
blocks of code: the first when it's TRUE, and the block after `else` when
it's FALSE.

Don't confuse it with `ifelse()` from module 9. Despite the similar name,
they're different tools. `if` takes a single TRUE or FALSE and runs code;
`ifelse()` takes a whole vector and gives back one value for each.

## Why R often doesn't need the loop

In many programming languages, doing the same thing to a set of values
*means* writing a loop. R is different: arithmetic on a vector already
happens to every value at once, which is what you've been doing since
module 5.

So why does generated R code have loops? Partly habit — AI models learn from
code in many languages, and often write R the same way. And sometimes a loop
is genuinely the right tool: when each step depends on the one before, or
when each step is a whole task of its own, like reading one file after
another. So a loop isn't a mistake. But when one is only doing simple
arithmetic, it's worth asking whether it could be a single line. Shorter
code has fewer places for a mistake to hide.
