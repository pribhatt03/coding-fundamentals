# 6. Missing values

Real data often has missing values:

- the cuff failed
- the measurement was never documented
- the patient left before the second draw

R has a value for "nobody knows," and writes it `NA` — in capitals, since R
is exact about names. Here's a shift of blood pressures where the second
reading is missing:

```r
sbp <- c(118, NA, 131, 156)
```

::: exercise {#ch06-ex01}

`NA` isn't text, and it isn't zero. It's a deliberate blank that fits into
whatever vector it's in. Compare that with the last module, where putting one
character value among numeric ones turned every value into character.

::: exercise {#ch06-ex02}

::: exercise {#ch06-ex03}

Anything calculated from an unknown value is itself unknown, so the answer
comes back as `NA`. That's R refusing to guess, rather than making a choice
on your behalf that you might not want.

## Saying what to do about it

Many of R's functions include missing values by default. If you want to
leave them out and work with only the values you have, you have to say so —
and because you say it in the code, that decision is written down where
anyone can see it.

::: exercise {#ch06-ex04}

## Finding the missing values

::: exercise {#ch06-ex05}

There are two different questions here, and R can only answer one of them.

*Is this reading equal to an unknown number?* R can't know, so every answer
is `NA`. That's the question `==` asks.

*Is this reading missing?* R knows that for certain. That's a different
question, and it has its own function: `is.na()`.

::: exercise {#ch06-ex06}

::: exercise {#ch06-ex07}

When a result from your analysis comes out strange — an average that's
`NA`, or a count that looks too high — `sum(is.na(x))` is a good thing to
reach for. It tells you
straight away whether missing values are part of the problem.

Missing data is normal, and your code can handle it and leave a record of
what you chose to do. The harder problem is a missing value that's easy to miss: a
zero standing in for a missing value, sitting among measurements that are
real. R can't tell it from a genuine zero, so the only one who can catch it
is you.
